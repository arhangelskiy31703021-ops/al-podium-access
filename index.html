Доступ через Supabase: пользователь входит по email/паролю и подтверждает общий код доступа.

1
Общий кодКод хранится на стороне Supabase и может быть изменён владельцем.
2
ПользователиРегистрация через email/пароль; пользователей можно удалять в Supabase Auth.
3
Без пароля в HTMLВ файле нет общего кода и нет его хэша — проверка идёт через RPC.

Вход в приложение

Введите email, пароль и общий код доступа.
Для GitHub Pages: вставь SUPABASE_URL и SUPABASE_ANON_KEY в код файла index.html.
